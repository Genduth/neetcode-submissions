# NeetCode Learning Log

This journal records what was practised, what the learner demonstrated independently, what still needs support, and the next useful step. It is evidence of progress rather than a list of videos watched.

## Understanding states

- **Secure:** explained in the learner's own words and applied to a fresh example without a decisive hint.
- **Developing:** partially understood or completed with meaningful prompting; revisit when relevant.
- **Not assessed:** introduced but not yet demonstrated.

These states are temporary and topic-specific, not grades.

## Entry template

```markdown
# YYYY-MM-DD — Session title

## Focus
- What I intended to practise

## What I can now explain or do
- Claim supported by a concrete example

## Evidence
- Problem, prediction, explanation, or code completed independently

## Still developing
- Exact point where reasoning or syntax became uncertain

## Mistake that taught me something
- What I expected
- What actually happened
- The corrected mental model

## Next session
1. Smallest useful next step
2. One transfer problem
3. One concept to revisit only if needed
```

## Logging rule

Do not mark a topic secure only because an answer was recognised after a prompt. Prefer evidence that the idea can be explained and transferred to a different example.
